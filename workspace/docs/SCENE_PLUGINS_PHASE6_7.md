# 场景插件与时序推理

最后核验：2026-09-23

## 养老辅助判断

`elderly_care` 使用 `MedicationSequenceReasoner`，按同一人物、同一药品对象和时间窗匹配拿取/接近与手部接近面部事实：

- 完整序列输出 `suspected_medication`；
- 药柜、药架、药房等储存/地点标签不当作药品本体；显式 medicine/medication/drug 类别可覆盖该负向词项；
- 主体显式标成设备/物品时，即使携带 ID 也会被拒绝；只有缺少主体标签的旧事实保留 ID 兼容路径；
- 有药品拿取线索、但没有匹配动作时输出 `incomplete_medication_sequence`；
- 只有同一人物和同一对象的放下事实会作为支持证据；
- 置信度使用必需事实中的最低值；
- 候选去重优先按实体 ID；药品 ID 缺失时按规范化标签区分对象，避免不同无 ID 药品在同一时刻被合并；
- 所有事件保留原始事实并要求人工复核，不作医疗诊断。
- JSONL 恢复模式产生 `observation_gap` 后，服药动作必须与拿取事实处在同一连续段；坏行前的状态不会跨间隙完成服药配对。

## 工作室/实验室物品

`workshop` 使用 `WorkshopStateReasoner` 处理移出、归还和缺失：

- `object_removed` / `left_zone` 产生移出事件；关系层 `left_zone` 从 subject 读取物品 ID。每个对象的待归还状态按区域分别维护，避免在 B 区移动覆盖从 A 区离开的记录。
- `object_returned` 可直接产生归还事件；`entered_zone` 只有在物品先离开并回到同一 `zone_id`（或同名区域）时才算归还；
- `putdown_candidate` 只表示人与物体拉开距离，不单独证明物品已归还；
- 显式 `object_missing` 可产生缺失事件；带区域标注时仅消耗对应区域的待处理移出状态，未标区域时沿用全局事实语义；
- 超时缺失要求 120 秒后出现明确 `scene_observed` 事实，并保留移出与观察两条证据；移出和观察都带区域标注时只接受同一区域，未标注区域的观察按全场覆盖处理；直接区域对象也校验非空 ID/标签、有限数值尺寸和唯一 ID；
- 缺失事件仍需人工复核。
- `observation_gap` 会清空待归还状态，后续观察不能借用间隙前的移出事实推断缺失。
- 即使调用方未附带 `observation_gap`，移出、归还/缺失和 `scene_observed` 的 `continuity_segment` 不一致时也不会跨段配对。

工作室同一对象在同一时刻不同区域的移出/缺失候选按区域分别保留；同一区域的重复候选仍合并。每次插件评估按一次事实集合推理，跨分析任务的持久对象状态还未实现。

## 验证与限制

养老和工作室插件都已调用时序推理器；当前 reasoner/plugin 定向测试 `103 passed`，覆盖身份/对象关联、标签回退去重、非人物主体和药品文档标签拒绝、创建后变更置信度复核与大整数输入校验、时间顺序与窗口、相同时间戳不推断状态转换、观察间隙、不一致连续段和显式来源不跨段配对、错误候选拒绝、UTC 归一化、区域 ID 匹配、超时观察证据和插件事实保留。当前 AI 全量测试 `414 passed`，详见根目录 `agent-state/TEST_EVIDENCE.md`。

这些测试使用构造事实和 Mock，不代表真实视频识别准确率。`FrameFactExtractor` 现在能把显式关键点 fixture 转为 `hand_to_face`，但没有经过验证的真实手部/姿态模型来提供关键点，也没有生成 `scene_observed`。服务默认区域列表为空；可通过 `AI_ZONES_JSON` 配置矩形，API/service 的离开与返回链已有 JSONL 回归覆盖。当前没有真实摄像头区域校准，持续 `scene_observed` 事实源也未实现；因此真实视频完整服药识别、现场区域转移和自动超时缺失仍需上游语义事实与经校准的区域配置。算法规则细节见 `TEMPORAL_EVENT_REASONING.md`。
