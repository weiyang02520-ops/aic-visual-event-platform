# AIC 机器人智能识别项目工作区

## 从哪里开始

1. 先读项目根目录的 `项目交付索引.md`；
2. 看 `agent-state/MASTER_STATUS.md` 和 `CURRENT_TASK.md`；
3. AI 服务见 `ai-engine/README.md`；
4. 前端见 `frontend/README.md`；
5. 比赛文档材料见 `docs/COMPETITION_MATERIAL_PACK.md`；
6. 可提交暂存包见 `submission/`。

## 目录约定

- `source-snapshots/`：Makerverse 和 livestream-rs 的只读源码快照；
- `ai-engine/`：独立 AI 分析服务；
- `frontend/`：React/Vite 控制台；
- `docs/`：设计、接口、证据、实验和比赛材料；
- `submission/`：筛选后的阶段性干净包，不含 agent-state、缓存、运行数据库、依赖目录和模型权重。

当前阶段仍等待老师主文档、机器人资料、真实媒体部署和授权数据。所有 Mock、CPU baseline 和本地 HTTP 结果都在文档中明确标注，不能当作真实比赛指标或机器人实机证据。
