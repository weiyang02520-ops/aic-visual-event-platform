# 第三方依赖说明

本文件只记录当前源码直接使用或构建时需要的主要依赖。版本会随安装环境变化，提交前应以锁定文件和许可证全文复核为准。

## AI 服务

| 依赖 | 用途 | 许可证/来源状态 |
|---|---|---|
| FastAPI | REST API | 上游许可证需随发布版本复核 |
| Uvicorn | ASGI 服务 | 上游许可证需随发布版本复核 |
| Pydantic | schema 校验 | 上游许可证需随发布版本复核 |
| python-multipart | 表单/文件解析预留 | 上游许可证需随发布版本复核 |
| pytest | 测试 | 仅开发依赖，上游许可证需复核 |
| httpx | API 测试客户端 | 仅开发依赖，上游许可证需复核 |
| NumPy/OpenCV/Pillow | 可选本地帧/图像能力 | 当前环境提供；未将权重或二进制打入包 |

|---|---|---|
| React / React DOM | UI 渲染 | 上游许可证需随锁定版本复核 |
