# AI 算法参考材料审计

最后核验：2026-09-23

## 范围与证据边界

本审计阅读了项目 `算法精英/` 目录中的四份 DOCX：`智隐云眸最新V1.docx`、`物联网应用类作品技术文档【终稿】002.docx`、`面向复杂实验室环境的多模态感知 (1).docx`、`MoMaGen.docx`。材料中出现的方案、模型名、数值、专利描述和实机结果属于各自文档的主张或引用，不会自动成为本项目的设计决定或验证结果。文档中的批注式文字，例如“这类的是不是用图做好看点”，是源文档内容，不是本次工作的用户指令。

## 1. 智隐云眸最新 V1

文档讨论了人体骨骼化、卡通化展示、HRNet/MediaPipe 关键点、2S-AGCN 动作分类、YOLO 物品检测、ByteTrack 加卡尔曼滤波、音视频融合，以及 UWB 与视觉结合的轮椅跟随。与本项目最相关的是“最小化人体数据”和“动作识别要同时利用空间结构与时间变化”两条设计思路。

隐私描述需要谨慎区分处理位置：文档部分内容把卡通化放在图像上传或云端存储之后；这能降低回放画面的可识别性，但不能证明原始画面没有离开相机，也不能证明传输和存储阶段已脱敏。当前 AI 引擎只接受显式 fixture keypoints；没有 HRNet、MediaPipe、2S-AGCN、音视频融合或真实 UWB 输入。因此这些算法名只作为上游替换方向，不计入当前实现。

文档报告的跟踪改进比例和识别结论缺少与本项目相同的数据、基线、指标定义及可复现实验环境，不能移植成当前性能主张。可复用的审计问题是：轨迹缺失时是否降低动作结论、人物 ID 是否稳定、关键点置信度和遮挡如何传播到事件置信度。

## 2. 物联网应用类作品技术文档

该文档描述 AlphaPose 骨骼关键点、YOLO 目标/药品检测、骨骼式回放、姿势识别和药品管理测试；表格包含模型 AP 对比以及 20 次左右的小样本测试计数。它可作为竞赛材料结构与场景说明的参考，但表格未完整说明数据来源、训练/验证/测试隔离、类别定义、标注协议、置信区间和硬件/软件版本，数值不能作为当前项目的基线或验收值。

可迁移到本项目的测试设计：将检测、关键点、跟踪、时序事件分层计分；同时报告误报、漏报、拒识和端到端延迟；对隐私回放单独检查原始帧是否保留。当前对应路径仍是 fixture/CPU 规则，不能据参考表推断真实模型指标。

## 3. 面向复杂实验室环境的多模态感知

材料提出 RGB/事件相机自适应融合、热成像风险推理、PGSR 语义世界模型、VLA 任务规划、QP 安全过滤、力觉/触觉反馈和失败经验学习，并列出目标指标。它主要面向轮式双臂实验室机器人，与当前养老/工作室视觉事件引擎的输入和任务范围不同。指标以目标值或方案描述出现，不能视为实测结果；文中编辑提示也不属于用户要求。

可迁移的是工程方法而不是整套模型：为每种输入记录可用性/质量，低质量或缺失传感器时降级或拒识；把安全阈值、算法候选和硬件执行分层；以失败案例构造独立测试。当前引擎还没有事件相机、热成像、PGSR、VLA 或机器人安全控制接口，因此不新增这些伪接口。

## 4. MoMaGen

该研究把移动操作演示生成写成约束优化：任务成功、可达性、碰撞和操作时可见性属于硬约束，导航时可见性与收回动作属于软约束；通过多种场景随机化、对照/消融和有限真实演示评估模拟到真实迁移。文档同时明确指出依赖完整场景知识、计算资源较大，并且真实硬件上的绝对成功率可能仍低。

对本项目的启发是区分“必须满足的证据门槛”和“可优化的体验目标”。例如，同一人物/对象/时间与连续段可作为事件推理硬约束；减少延迟、保留更多候选可作为软目标。模拟或合成样本应与真实验证分开，展示模拟到真实落差，而不是把合成结果当部署效果。MOMAGEN 的机器人轨迹生成不适合直接移植到当前事件推理器。

## 当前代码审计发现

本次对照隐私骨骼化参考时，复核了 `/api/v1/sources/frames` 的数据输出：已有逻辑会脱敏顶层 `image`、`gray` 等像素字段，但嵌套对象中的 `Image-Data`、`depth_map`、`raw_pixels` 仍可能绕过顶层检查。已将帧预览序列化改为递归处理，并对常见图像、RGB/BGR、灰度、像素、深度和帧数据字段只返回编码/尺寸摘要；非图像的姿态关键点、标签和对象检测字段仍保留。新增嵌套 JSONL API 回归验证该边界。

这只证明 REST 预览序列化对所列键和测试形状的处理，不证明任意自定义字段都能识别为图像，也不证明相机端/边缘端从源头丢弃原始帧。真实姿态模型、授权数据、隐私保留审计和机器人证据仍缺失。

## 后续验证清单

- 接入真实姿态/检测模型前，固定数据授权、标注协议、拆分方式、类别映射和模型版本；
- 关键点/跟踪测试按遮挡、漏帧、多人交叉和视角变化切片，单列轨迹中断和 ID switch；
- 多模态输入按传感器质量做故障注入，验证低质量通道不会被误当成有效证据；
- 事件级报告 precision/recall/F1、误报漏报、拒识率、延迟和资源占用，保留原始预测与评估脚本；
- 隐私验证检查相机侧、网络传输、REST、日志、SQLite、证据存储和演示回放各层，不以 UI 卡通化替代源头脱敏。
