# 创新点与可验证性

## 1. 通用视觉事实层与场景插件层分离

底层只负责帧、检测、跟踪、关系和时间事实；养老、工作室和未来机器人场景通过插件解释。创新性来自可迁移的系统组合，而不是单独使用 FastAPI、React 或某个模型。当前有源码、manifest、插件测试和 fixture 证据；跨场景真实准确率尚待实验。

## 2. 自动发现、并行和可控的场景插件

新插件放入目录后自动发现，前端可以全局启停，多插件共享事实链。异常被隔离并记录 degraded 状态。当前已通过本地测试，分布式部署、权限控制和高并发未验证。

## 3. 长尾物品低门槛注册

对象登记不要求立即重新训练完整检测器，允许以参考图/embedding 作为可替换注册信号。当前实现的是 CPU heuristic 和 REST 契约，生产版本必须补充多图质量门控、隐私存储、拒识和真实评估。

## 4. 从单帧检测到可解释事件

事件回答“谁、在什么时间、什么位置、对哪个对象做了什么”，通过时间窗、去抖、冷却和关系事实减少单帧误报。当前规则事件可回归测试，不能替代真实数据集上的事件级指标。

## 5. AI 结论与历史视频证据协同

不确定结论保留证据时间窗和 resolver 状态，允许人工复核。系统把 fixture、已提供未验证、可回放和不可用区分开，避免把模型输出包装成绝对事实。真实 HLS/HTTP-FLV 证据链待部署后验证。

## 6. 软件底座与机器人执行解耦

AI 与前端可独立运行，未来通过机器人 adapter 连接移动底盘、相机和动作执行。当前机器人只保留接口占位；具体动作、协议、安全和硬件能力必须以老师资料及实机验收为准。

## 7. 创新表述规则

最终材料不得写“已达到某准确率”“已完成机器人闭环”等无证据结论。每个创新点同时列出实现证据、Mock 证据、真实验证缺口和下一步实验。
