## 1. Objective

Make the existing local OpenCV video path provide a model-ready pixel frame to real vision providers while preserving the current grayscale CPU-motion path and all privacy/evidence boundaries.

The intended chain after this task is:

```text
local MP4/AVI
→ OpenCVFrameProvider
→ BGR image + gray helper payload
→ optional real detector/pose provider
→ existing tracker/fact/plugin/event pipeline
```

Do not run or claim a real Ultralytics model in this task; real-model runtime smoke is a later bounded task.

## 2. Why This Task Now

TASK-0001 added and verified the optional Ultralytics pose adapter contract, but the current OpenCV provider places a grayscale ndarray in `payload["image"]`. That is sufficient for the CPU motion baseline but is not the stable intended input contract for a real image/pose model.

This task closes the local-video-to-provider bridge without adding network/model-weight dependencies.

## 5. Exact Requirements

1. Change `OpenCVFrameProvider` so sampled local-video frames expose:
   - `payload["image"]`: the decoded BGR frame suitable for real image-model providers;
   - `payload["gray"]`: the grayscale frame/matrix used by the existing motion baseline;
   - safe shape/channel metadata as needed, without duplicating pixels in persisted/event metadata.
2. Keep existing timestamp/FPS/read-index behavior unchanged unless a concrete bug is found.
3. Ensure `MotionDetector` continues to use the grayscale path and does not attempt to interpret 3-channel BGR pixels as scalar gray values.
4. Add deterministic tests proving the OpenCV payload contract. Tests must not require internet, GPU or model weights.
5. Add an integration test that drives a local-video/OpenCV-style frame through a fake/stub Ultralytics provider and into the existing normalized observation/fact path, proving source/timestamp/keypoint metadata survive.
6. Add/extend privacy regression coverage proving raw BGR/gray pixel arrays are summarized/redacted before they can appear in public preview/job/event/SQLite metadata.
7. Preserve Mock/JSONL/fixture/motion paths.
8. Keep real-model runtime explicitly unverified in docs/state.
9. Synchronize curated submission copies only after source tests pass.
