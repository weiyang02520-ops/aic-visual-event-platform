   - local ignored path;
   - device used (CPU unless environment safely provides another device).
3. Run the actual model through `UltralyticsProvider`, not only by directly calling Ultralytics APIs.
4. Prove a real model load and inference call completed without a fake/stub model.
5. Prefer a sample containing a person so the normalized output includes at least one person bbox and, when provided by the model, `nose`, `left_wrist`, `right_wrist` keypoints.
6. If the first authorized sample yields no person, one additional official/public sample may be used. Do not keep searching indefinitely.
7. Record a small sanitized smoke artifact under `workspace/docs/` or `agent-state/` containing only:
   - runtime/package/model identity;
   - sample source description;
   - count of normalized detections;
   - presence/absence of required keypoints;
   - coarse diagnostic wall-clock timing if easy to capture, explicitly labeled non-benchmark;
   - no raw image pixels, no model weights.
8. Run the existing full test suite after the smoke.
9. Run `VERIFY.ps1 -SkipFrontendBuild`.
10. Keep weights/samples/runtime caches untracked and verify `git status` is clean except intentional source/docs/state changes.
