# TASK-0014

## Title

Plugin Runtime System

## Dependencies

- TASK-0011
- TASK-0012

## Goal

实现真正插件化架构，使新增插件无需修改核心页面。

## Scope

### Plugin Registry

支持注册插件、获取插件列表和启用/关闭。

### Plugin Lifecycle

状态包括 `registered`、`enabled`、`running`、`disabled`。

### Dynamic UI

插件开启时显示对应组件，插件关闭时隐藏对应组件。

## Files

新增：`workspace/frontend/src/plugins/`，可包含 `registry.ts`、`loader.ts`、`types.ts`。

## Acceptance

- 插件状态来自 Contract；
- UI 根据插件状态变化；
- 至少支持 medicine 和 object。

## Forbidden

- 修改 AI 插件代码；
- 修改 backend 插件服务；
- 使用大量动态代码生成。
