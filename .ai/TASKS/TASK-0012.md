## Goal

将当前简单事件展示能力升级为完整 AI Event Center。

目标：让用户能够查看 AI 生成事件、事件来源插件、AI 判断结果、推理链和证据链，形成“AI 识别 → 事件生成 → 解释展示”闭环。

## Scope

### Event List

支持时间排序、类型筛选、插件来源显示和置信度显示。事件字段包括 `event_id`、`timestamp`、`event_type`、`plugin_id`、`confidence`、`status`。

### Event Detail Drawer

点击事件打开详情，展示时间、人物、物品、动作链、AI 判断和 Evidence。

### Evidence Display

支持展示 pose evidence、object change、action evidence 和 reference URI。
