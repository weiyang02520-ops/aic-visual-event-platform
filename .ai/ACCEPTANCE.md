# Project Acceptance

Only Master may mark DONE.

1. Independent AI service starts, exposes API, persists events, runs core pipeline.
2. Plugins auto-discover, multiple run, global enable/disable works.
3. At least one optional real visual-model provider path exists with truthful availability/normalized output; real runtime evidence is separately identified.
4. Elderly/workshop plugins produce reviewable events, not medical certainty.
5. Events use source/time evidence refs; AI does not duplicate video archive.
6. Frontend has complete Mock demo + Real AI adapter and core pages.
7. Backend integration is adapter-based, not broad rewrite.
8. Critical AI/plugin/API/frontend paths are reproducibly verified.
9. No unmeasured performance/camera/sensor/robot claim is presented as verified.
10. Final submission excludes .ai, agent-state, secrets, caches, runtime DBs, dependencies, prompts and local paths.
11. Technical docs are usable for competition document fusion.
12. Final report distinguishes implemented, verified, Mock, degraded, blocked and future items.
