# Open Questions

这些问题不阻塞当前软件原型，但必须在最终融合和实机验收前由老师文档、机器人资料或部署方回答。未回答前不得把假设写成事实。

## 比赛与文档

1. 最终报名赛道、评分点、篇幅、格式、截止时间和必交附件是什么？
2. 老师主文档哪些章节必须保留，哪些章节允许插入 AI/前端内容？
3. 是否有官方 Word/LaTeX 模板、封面、图表和引用规范？
4. 团队名称、成员、指导教师和成果数据由谁最终确认？

## 机器人与部署

1. 机器人具体型号、操作系统、算力、相机和网络拓扑是什么？
2. 视频来自机器人相机、Makerverse 直播还是 livestream-rs 转发？
3. 通信协议、控制 API、动作安全边界和回滚方式是什么？
4. 是否允许安装依赖、重启服务或修改机器人基础系统？
5. 真实部署的地址、鉴权、CORS、时间同步和日志获取方式是什么？

## 数据与模型

1. 是否有经授权的视频/图像数据、标注和隐私审批？
2. 最终类别、事件定义、拒识规则和评价指标是什么？
3. 是否提供 GPU、模型权重和已验证的输入/输出 adapter？
4. 真实指标的设备、分辨率、采样率和测试集划分如何固定？

## 已采取的处理

在问题回答前，系统继续使用 Mock、CPU baseline、可替换 provider、明确 evidence 状态和机器人 adapter 占位；相关状态记录在 `BLOCKERS.md` 和材料包中。
